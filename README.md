# 정보시스템 감리사 · 최단기 합격 개념서

스마트폰 출퇴근용으로 설계된 **정보시스템 감리사 13개년(2014~2026) 1,560문항 · 104토픽 · 기술사 연계 868문항** 통합 개념서 웹앱입니다.

- **웹 접속 주소**: https://sezlim.github.io/garisa-concept/
- **오프라인 실행**: 저장소 파일을 내려받아 `index.html`을 더블클릭하면 서버 없이 바로 열립니다.

## 핵심 기능
- **01 출제 의도 & 최단 공략법**: 13개년 출제 빈도 스파크바, 출제 유형 비율, 3초 풀이 포인트
- **02 핵심 개념 & 비교·암기표 + 블라인드 암기**: 핵심 수치·키워드·비교표 셀을 가리고 탭하며 능동 회상
- **03 출제자 함정 설계 해부 (516건)**: 6대 함정 설계 기법 분류 + 기출 실증 근거
- **04 오늘의 10분 & 함정 플래시 (828장) & 합격 레이더**: 망각곡선 복습(1·3·7일) + 5과목 과락 방어 모니터링
